Research

Efficient systems, from the processor to the edge.

My work combines computer architecture, embedded and edge systems, and hardware-accelerated data processing, with a foundation in processor memory subsystems.

01 / Computer architecture

Processor and memory architecture

Design and evaluation of secure, energy-efficient, high-performance architectures, including processor microarchitecture, workload characterization, and memory-subsystem performance modeling.

MicroarchitecturePerformance modelingWorkloads
02 / Memory systems

Caches and emerging memory

Management of on-chip caches and investigation of modern memory technologies, including 3-D stacked memory, HMC, HBM, and non-volatile STT-RAM.

Cache hierarchy3-D stacked memorySTT-RAM
03 / Edge & embedded systems

Efficient computing at the edge

Architectures and embedded platforms that support capable, dependable, and efficient processing close to the source of data.

Edge computingEmbedded systemsEnergy efficiency
04 / Hardware acceleration

Accelerated data processing

Domain-specific and processing-in-memory architectures for graph analytics and other data-intensive applications, while considering hardware security and cache side channels.

Graph analyticsPIMHardware security

Current research direction

Bringing together architectural innovation and workload awareness to develop practical hardware systems for data-intensive computing.

Doctoral research

Improving Performance of Modern Memory Subsystem

Joint Ph.D. from IIT Bombay and the National University of Singapore, advised by Prof. Virendra Singh and Prof. Trevor E. Carlson.

The work developed PIM accelerators for graph analytics, evaluated 3-D stacked memories, improved hybrid-cache performance and energy efficiency, and introduced cache-management policies using the Sniper architectural simulator and BookSim network simulator.
