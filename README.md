# Newton — Academic Website

A professional, responsive multi-page faculty website based on `NewtonResume_Detailed.pdf` (updated 20 July 2026), the supplied portrait, Newton's official BITS Pilani faculty profile, publisher records, and official conference programs.

## Site structure

- `index.html` — concise academic homepage
- `research.html` — research interests and doctoral work
- `experience.html` — professional, research, and teaching timeline
- `publications.html` — complete searchable and filterable publication list
- `academic.html` — academic background, recognition, technical interests, and service
- `contact.html` — official BITS email, office, and professional profiles
- `404.html` — GitHub Pages fallback page
- `assets/css/main.css` — shared visual design and responsive layout
- `assets/js/main.js` — mobile navigation and publication filtering
- `assets/images/` — edited portrait and favicon
- `assets/docs/` — downloadable detailed CV

The public contact information uses Newton's official BITS Pilani email (`newton@goa.bits-pilani.ac.in`) and excludes telephone details. Publication entries link to their publisher pages, official paper PDFs, or official conference records where proceedings are not yet publicly available.

## Preview

Open `index.html` in a browser. No build step or package installation is required.

## Publish with GitHub Pages

1. Create a GitHub repository.
2. Upload all contents of this folder to the repository's default branch.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the default branch and the **/(root)** folder, then save.

All internal URLs are relative, so the site works as either a user site (`username.github.io`) or a project site (`username.github.io/repository-name`).

No GitHub deployment has been performed.
